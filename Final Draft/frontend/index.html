About AI Lifestyle Chatbot

Overview

AI Lifestyle Chatbot is a 100% offline, privacy-focused AI assistant designed to help you with nutrition, fitness, and wellness guidance.

Features

  • Multi-language support (7 languages)
  • RAG-powered responses from knowledge base
  • Conversation history storage
  • Daily meal and exercise planning
  • Reminder system
  • Accessibility features
  • 100% offline operation
  • Complete data privacy

Technology Stack

LLM: Llama 3.2 via Ollama
RAG: ChromaDB + Sentence Transformers
Translation: Argos Translate
Backend: FastAPI + SQLite
Frontend: HTML/CSS/JavaScript

Privacy & Security

100% Offline: All processing happens locally on your device. No data is sent to external servers.

No Tracking: We don't collect, store, or transmit any usage data.

Local Storage: All conversations and data are stored locally in SQLite database.
